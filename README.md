# FOOD LAB Restaurant Management System

Student: W. H. D. Siriwardhana
University: South Eastern University of Sri Lanka

Technologies: PHP, MySQL, HTML, CSS, JavaScript, XAMPP

How to run:
1. Start Apache and MySQL in XAMPP.
2. Put this folder in C:\xampp\htdocs\food_lab
3. Import database/food_lab_restaurant.sql in phpMyAdmin.
4. Open http://localhost/food_lab/
